## Overview

In this lab, requirements engineering practices were applied to design a full lifecycle specification for a Digital Art Commission & Watermarking Portal.

### Key Deliverables:
1. **`use_case_diagram.drawio`**:
   - UML Use Case Diagram capturing primary actors: `Client Buyer` and `Digital Artist`.
   - Core use cases:
     - Submit Creative Brief
     - Apply Watermark Overlay
     - Submit WIP Draft
     - Request Revision
     - Upload Final Source Files
     - Download Final Artwork
2. **`Digital_Art_Commission_Watermarking_Portal_RTM_PES2UG24CS917.docx`**:
   - Comprehensive Requirements Traceability Matrix (RTM).
   - Maps each functional requirement (`FR-001` to `FR-005`) and non-functional requirement (`NFR-001` to `NFR-004`) to architectural models, detailed design artifacts, implementation units, unit tests, functional tests, system tests, and user acceptance criteria.
